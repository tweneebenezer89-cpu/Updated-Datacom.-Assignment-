2. Analog vs Digital Transmission (ASK, FSK, PSK, QAM)

Modulation converts bits into waveforms. Different schemes trade off bandwidth, noise tolerance, and complexity.

• ASK: amplitude changes • FSK: frequency changes • PSK: phase changes • QAM: amplitude + phase in a constellation.

3. Transmission Media (Twisted Pair, Coaxial, Fiber Optic)

Different media offer trade-offs among bandwidth, distance, noise immunity, and cost.

  • Twisted Pair — two conductors twisted to reduce EMI
  • Coaxial — central core + shield for better shielding
  • Fiber Optic — light pulses for maximum bandwidth & distance
Noise immune ↑
Bandwidth ↑
Distance ↑

4. Error Detection & Correction (CRC, Checksum, Hamming Code)

Techniques add redundancy so receivers can detect (and sometimes correct) corrupted bits.

Senderdata bits
Encode redundancyCRC / checksum / Hamming
Transmitchannel noise may alter bits
Receiverre-check & syndrome
Outcomedetect ✓ / correct bit ✓
• CRC: polynomial remainder detection • Checksum: sum-based verification • Hamming: parity bits to correct single-bit errors.

5. Multiplexing & Switching (FDM, TDM, WDM, Circuit/Packet Switching)

Shared links use multiplexing; network devices choose how data flows using switching strategies.

TDMSeparate by time slots
WDMOptical wavelengths (dense)
SwitchingCircuit vs Packet
• Circuit switching reserves a path • Packet switching shares links dynamically for efficiency.

6. Flow Control & Buffering (Stop-and-Wait, Sliding Window)

Flow control prevents a fast sender from overwhelming a slow receiver by managing the rate of data.

Windowtracks allowed frames
Receiverchecks buffer space
FeedbackACK / Window update
Resultstable delivery
• Stop-and-Wait: simple, lower throughput • Sliding Window: higher throughput.
